Living Wall · Phase 1 · Scene Catalog

18 scene terkurasi — siap dipanggil lewat JSON API.

Setiap scene di sini sudah dipasangkan dengan parameter WLED konkret. Tujuannya bukan menampilkan semua ~180 efek bawaan, tapi kurasi 18 mood yang berarti — yang user kenali lewat nama, bukan effect ID. Catalog ini = data yang mengisi galeri scene di seluruh dokumen desain.

⚠ Penting — fx IDs di catalog ini adalah placeholder 1D-era. Wall sekarang dirender sebagai WLED 2D Matrix (grid serpentine), bukan strip 1D. Sebelum production, tiap scene harus di-remap ke 2D effect (Plasma 2D, Polar Lights, Fire 2D, Sunrise 2D, dll) dan divalidasi di hardware lintas 3 aspect class. fx ID + parameter di card di bawah adalah starting point untuk tuning, bukan final spec.

Catatan Implementasi

Catalog ini adalah data, bukan firmware.

18 scene di atas tinggal di aplikasi Flutter kamu, bukan di WLED. WLED tetap stock — tidak ada preset yang disimpan ke device. Yang dikirim ke wall adalah JSON payload di atas, satu request per pemilihan scene. Bagian ini menjelaskan bagaimana data ini hidup di kode.

Model data

Setiap scene jadi satu objek immutable dengan defaults yang sudah ditune. Sheet penyesuaian (brightness · speed · intensity) hanya meng-override tiga field — selebihnya tetap.

enum SceneCompatibility { universal, landscape, portrait } class Scene { final String id; final String name; final SceneCategory category; final SceneCompatibility compatibility; // for gallery sort + badge final String description; final String useCase; final int defaultBri; final int fx; // MUST be 2D effect ID final int pal; final int? defaultSx; final int? defaultIx; final List<int>? col; }

Mengirim ke wall

Wrap satu fungsi yang menerima scene + override opsional, hasilkan JSON, POST ke /json/state wall. Untuk grup: ubah satu wall, sisanya ikut via UDP sync (sudah dibahas di spec). Prerequisite: wall harus sudah di-provision sebagai 2D matrix lewat WledClient.configureMatrix() di add-wall flow — tanpa itu, scene 2D akan tetap render seakan strip 1D.

Future<void> applyScene( Wall wall, Scene scene, { int? briOverride, int? sxOverride, int? ixOverride, }) async { final payload = scene.toJson( bri: briOverride ?? scene.defaultBri, sx: sxOverride ?? scene.defaultSx, ix: ixOverride ?? scene.defaultIx, ); await http.post('http://${wall.ip}/json/state', body: jsonEncode(payload)); }

Transisi halus

Field "transition": 14 (14 × 100ms = 1.4 detik) ada di tiap payload. Itu yang membuat perpindahan scene terasa lembut, bukan loncat. Untuk Wind Down naikkan ke 30 (3 detik) supaya senjanya benar-benar pelan.

Quick scene vs sheet

Sesuai keputusan desain: tap quick scene = kirim defaults langsung, tanpa sheet. Sheet hanya muncul dari galeri "Lihat semua". Itu sebabnya defaults harus ter-tune — 80% interaksi tidak akan pernah menyentuh slider.

Menambah scene ke-19

Karena scene = data, menambahkannya tidak perlu rilis app baru kalau kamu memuatnya dari backend (Phase 2+). Phase 1 local-first → tambah scene = update file aset + rilis. Mulai konservatif: 18 scene cukup untuk semua mood harian.

Cara tuning di hardware

Aspirasi vs realita kadang berbeda. Uji tiap scene di wall sungguhan sebelum finalisasi — terutama brightness (LED terang di datasheet bisa silau di dinding) dan speed (apa yang terlihat di simulator beda dengan pada grid 72×48 atau 108×72). Tune sampai sesuai deskripsinya, lalu kunci angkanya. Lintas 3 aspect class: validasi universal scenes di satu panel reference saja cukup; landscape + portrait scenes butuh sample panel yang match — minimal 1 unit M (1.2×0.8m, landscape) plus 1 unit portrait sample (0.8×1.2m atau serupa).

Pemetaan fx ke 2D effect

fx ID di tiap card adalah placeholder dari era 1D. Sebelum production, tiap scene harus dipasangkan ke effect 2D di WLED 0.14+. Draft awal mapping:

// universal — most carry over with similar feel candle, breathe → solid + bri pulse focus, daylight → solid fireplace → Fire 2D twinkle, sakura → Plasma 2D + palette forest, movie, party → Plasma 2D / Drift 2D // landscape — horizon / horizontal flow ocean → Drift 2D atau Plasma 2D (low speed) sunset → Sunrise 2D atau custom gradient golden → Sunrise 2D variant aurora → Polar Lights 2D tokyo → Color Waves 2D // portrait — vertical flow rain → Matrix 2D (vertical) dawn → vertical gradient (slow transition 30) dinner → vertical glow / soft solid

Validasi A/B di hardware vs deskripsi tiap scene. Output langsung ke assets/scenes.json production.

Aspect compatibility & gallery sort

Saat user buka scene gallery dari wall control, gallery sort 18 scene berdasarkan match dengan wall.aspectClass:

1. Scene dengan compatibility matching wall di atas
2. Universal scenes di tengah
3. Mismatched scenes di bawah, dengan label kecil "kurang optimal untuk wall ini"

Tidak pernah hide, tidak pernah disable. User tetap bisa apply scene apapun — keputusan ada di user. Premium UX = informatif, bukan restriktif.
